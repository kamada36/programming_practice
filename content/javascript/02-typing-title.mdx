## 仕組み

`setInterval(関数, ミリ秒)` は、一定間隔で関数を呼び続けます。
ここでは 120 ミリ秒ごとに「文字列の先頭から `i` 文字目まで」を表示しています。

```js
el.textContent = text.slice(0, i);
i += 1;
if (i > text.length) clearInterval(timer);
```

`text.slice(0, i)` の `i` が 1, 2, 3... と増えることで、
表示される文字が少しずつ伸びていきます。
最後まで表示したら `clearInterval` でタイマーを止めます。

<Callout type="warn">
`clearInterval` を書き忘れると、タイマーが永遠に動き続けます。
「止める条件」を必ずセットで考えるのがコツです。
</Callout>

## 試してみよう

- `120` を `40` にすると、一気に速くなります。
- `text` を好きな文章に変えてみましょう。
