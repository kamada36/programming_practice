## 仕組み

データの本体は `todos` という **配列** です。
画面（`<ul>`）は毎回まるごと作り直します。

```js
function render() {
  list.innerHTML = "";
  todos.forEach((text, index) => { /* <li> を1つずつ作る */ });
}
```

- 追加：`todos.push(...)` してから `render()`
- 削除：`todos.splice(index, 1)` してから `render()`

「配列を変える → 画面を作り直す」の一方通行にすると、
表示とデータがズレなくなります。

<Callout type="warn">
`e.preventDefault()` を消すと、追加のたびにページが再読み込みされて
入力が消えてしまいます。フォームの定番の落とし穴です。
</Callout>
