## やっていること

`document.body.style.background = "..."` で、`<body>` の背景色を直接書き換えています。

```js
i = (i + 1) % colors.length;
document.body.style.background = colors[i];
```

`(i + 1) % 配列の長さ` は「次の番号。最後まで行ったら 0 に戻る」という定番の書き方です。

<Callout>
`style.background` を `style.color` に変えると、今度は文字色が変わります。
</Callout>
