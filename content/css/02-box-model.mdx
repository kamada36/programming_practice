## 何をしているの？

すべてのHTML要素は、内側から順に「内容 → padding（内側の余白）→
border（枠線）→ margin（外側の余白）」という **箱** になっています。
これを **ボックスモデル** と呼びます。

```css
.card {
  padding: 1.5rem;
  border: 1px solid #d9cfc4;
  border-radius: 12px;
  box-shadow: 0 4px 10px rgba(0, 0, 0, 0.08);
}
```

- `padding` … 内容と枠線のあいだの余白
- `border` … 枠線（太さ・種類・色）
- `border-radius` … 角の丸み
- `box-shadow` … 影（ぼかし・色を指定して立体感を出す）

<Callout>
`padding` を大きくしすぎると箱全体が広がってしまいます。
「箱の中の余白は padding、箱と箱のあいだの余白は margin」と覚えると混乱しません。
</Callout>

## 次の一歩

`box-shadow` の数値（`0 4px 10px`）を `0 8px 20px` にすると、
影がより大きく柔らかくなり、カードが「浮いて」見えるようになります。
