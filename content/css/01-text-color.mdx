## 何をしているの？

CSSは「どの要素に」「どんな見た目を」つけるかを指定する言語です。

```css
.card {
  background-color: #ffe8cc;
  color: #6b4423;
}
```

`.card` は **セレクタ**（`class="card"` が付いた要素を選ぶ）、
`{ }` の中がその要素に適用する **プロパティ：値** のペアです。

- `background-color` … 背景の色
- `color` … 文字の色

色は `#ffe8cc` のような16進数コードのほか、`orange` のような色名でも指定できます。

<Callout>
`background-color` と `background` は似ていますが、`background` は背景画像や
グラデーションなど、もっと多くの指定をまとめて書けるプロパティです。
</Callout>

## 次の一歩

`padding`（内側の余白）の数値を大きくすると、カードがひとまわり大きく、
ゆったりした見た目になります。試してみましょう。
