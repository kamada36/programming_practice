## 何をしているの？

複数のカードを横に並べたいときは、親要素に `display: flex` を指定します。

```css
.row {
  display: flex;
  gap: 1rem;
  flex-wrap: wrap;
  justify-content: center;
}
```

- `display: flex` … 直下の子要素を横並びにする
- `gap` … 子要素どうしの間隔
- `flex-wrap: wrap` … 画面が狭いときに折り返す
- `justify-content: center` … 横方向の中央寄せ

以前は横並びのために `float` を駆使する必要がありましたが、
Flexboxのおかげで **1行書くだけ** で済むようになりました。

<Callout>
縦方向の揃え位置を変えたいときは `align-items` を使います。
`justify-content` は「並んでいる向き」、`align-items` は「それと垂直な向き」を揃えます。
</Callout>
