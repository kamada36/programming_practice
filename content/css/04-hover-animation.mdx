## 何をしているの？

`:hover` は「マウスが乗っているあいだだけ」スタイルを変える疑似クラスです。

```css
.btn {
  transition: transform 0.2s, box-shadow 0.2s;
}
.btn:hover {
  transform: translateY(-3px);
  box-shadow: 0 8px 18px rgba(217, 119, 6, 0.45);
}
```

`transition` を書いておくと、`:hover` で値が変わる瞬間が
**カクッ** ではなく **なめらか** になります。指定した時間（ここでは0.2秒）
かけて値が変化します。

ページが表示された瞬間の演出には `@keyframes` を使います。

```css
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(8px); }
  to   { opacity: 1; transform: translateY(0); }
}
.btn {
  animation: fadeIn 0.5s ease-out;
}
```

`from` が開始時点、`to` が終了時点の見た目です。ボタンがふわっと
下から浮かび上がって表示されます。

<Callout>
`transform` はレイアウト（他の要素の位置）に影響を与えずに動かせるため、
`margin` などで動かすよりも滑らかでパフォーマンスの良いアニメーションになります。
</Callout>
