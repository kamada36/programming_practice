## 何をしているの？

ブラウザは、ユーザーの操作を「イベント」として教えてくれます。
このレシピでは **クリックされたとき** に動く処理を1つ登録しています。

```js
btn.addEventListener("click", () => {
  count += 1;
  btn.textContent = count + " 回 押したね！";
});
```

- `document.getElementById("btn")` … HTML のボタンを JavaScript から掴む
- `addEventListener("click", ...)` … クリックされたら中の関数を実行する
- `btn.textContent = ...` … ボタンの表示文字を書き換える

<Callout>
`count` の初期値を `10` に変えたり、`textContent` の文言を変えたりして、
プレビューがどう変わるか試してみましょう。
</Callout>

## 次の一歩

`click` を `mouseover`（マウスを乗せたとき）に変えると、
押さなくても反応するボタンになります。イベント名を差し替えるだけです。
