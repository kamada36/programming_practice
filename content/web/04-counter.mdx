## ポイント

値を持つのは `count` という変数ひとつだけ。ボタンはその値を増減し、
`render()` が「今の `count` を画面に書く」役割を持ちます。

```js
function render() {
  label.textContent = count;
}
```

**「状態を1か所にまとめ、表示は関数にまかせる」** のは、
規模が大きくなっても崩れにくい書き方です。

<Callout>
`render()` の中で `label.style.color = count < 0 ? "red" : "#6b4423"` を足すと、
マイナスのときだけ赤字にできます。
</Callout>
