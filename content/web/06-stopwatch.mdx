## 経過時間の考え方

タイマーは「0.05秒ごとに数を足す」のではなく、
**「開始時刻」と「今の時刻」の差** で経過時間を出します。

```js
startedAt = Date.now();
// 表示のたびに…
const now = Date.now();
timeEl.textContent = ((now - startedAt) / 1000).toFixed(2);
```

こうすると、`setInterval` の呼び出しが多少ズレても、時間は正確なままです。

<Callout>
一時停止に対応するため、止めたときの経過を `elapsed` に足しておき、
再開時は `elapsed + (今 - 再開時刻)` で表示しています。
</Callout>
