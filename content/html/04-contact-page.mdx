## 何をしているの？

ページ全体を意味のあるブロックに区切ると、内容が伝わりやすくなります。

```html
<header>...</header>
<main>...</main>
<footer>...</footer>
```

- `<header>` … ページ（や記事）の導入部分
- `<main>` … そのページの主役となる内容（1ページに1つ）
- `<footer>` … 補足情報や著作権表示など

フォームの部品もそれぞれ役割が決まっています。

```html
<label for="name">お名前</label>
<input id="name" type="text" />
```

`label` の `for` と `input` の `id` を同じ値にすると、
ラベルをクリックしただけで入力欄にカーソルが移動します。

<Callout>
`select` はドロップダウンの選択肢、`textarea` は複数行の入力欄です。
`input`だけでは表現できない入力パターンをカバーしてくれます。
</Callout>

## 次の一歩

`input type="text"` を `type="tel"`（電話番号）や `type="date"`（日付）に変えると、
スマートフォンで最適な入力キーボードが自動で表示されます。
