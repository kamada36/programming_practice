## 何をしているの？

画像は `<img>` タグ1つで表示できます（閉じタグはありません）。

```html
<img src="画像のURL" alt="画像の説明" width="160" height="160" />
```

- `src` … 画像ファイルの場所（URL）
- `alt` … 画像が見えない人・環境向けの説明文
- `width` / `height` … 表示サイズ

表は `<table>` の中に、行を表す `<tr>`、その中に見出しセル `<th>` と
データセル `<td>` を並べて作ります。

```html
<tr>
  <th>名前</th>
  <td>レジサン</td>
</tr>
```

<Callout type="warn">
`alt` を空のままにすると、画像の内容が伝わらない人がいます。
飾りだけの画像でなければ、必ず中身のある説明を書きましょう。
</Callout>

## 次の一歩

`<th>` を各行の先頭ではなく、表の一番上の行にまとめて置くと、
「項目名の行」と「データの行」がはっきり分かれた表になります。
