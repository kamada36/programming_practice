## 何をしているの？

複数の項目を並べるときは `<ul>`（順序なしリスト）と `<li>`（項目）を使います。

```html
<ul>
  <li>ドリップコーヒー ¥480</li>
  <li>カフェラテ ¥520</li>
</ul>
```

リンクは `<a href="飛び先">表示する文字</a>` です。

```html
<a href="#menu">↑ メニューの先頭へ戻る</a>
```

`href="#menu"` のように `#` から始めると、**同じページの中の要素** へジャンプできます。
飛び先は `id="menu"` を付けた要素です。

<Callout>
外部サイトへのリンクに `target="_blank"` を付けると新しいタブで開きます。
セキュリティ対策として `rel="noopener"` もセットで書くのが定番です。
</Callout>

## 次の一歩

番号付きの手順を書きたいときは `<ul>` の代わりに `<ol>`（ordered list）を使います。
タグを変えるだけで、自動的に「1. 2. 3.」の番号が付きます。
