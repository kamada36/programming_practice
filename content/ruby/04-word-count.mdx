## 文字列を分解する

```ruby
text.lines            # 行ごとの配列（改行付き）
text.split            # 空白で区切った単語の配列
text.gsub(/\s/, "")   # 空白（スペース・改行）を全部消す
```

`map(&:strip)` は「各要素に `strip` を呼ぶ」の短縮形。
`reject(&:empty?)` で空行を捨てています。

## 条件付きの最大・最小

```ruby
lines.max_by { |line| line.length }
```

`max_by` は「何を基準に最大とみなすか」をブロックで指定できます。
`min_by`、`sort_by` も同じ考え方です。

<Callout>
`<<~TEXT ... TEXT` は **ヒアドキュメント**。複数行の文字列を、
インデントを自動で取り除いて書けます。
</Callout>
