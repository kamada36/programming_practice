## each と map の違い

```ruby
drinks.each { |d| puts d }        # 表示したいだけ
lengths = drinks.map { |d| d.length }  # 変換した配列がほしい
```

- **each** … 1つずつ処理する。結果の配列は作らない
- **map** … 「各要素を○○した配列」がほしいときに使う

`do |x| ... end` と `{ |x| ... }` は同じ意味です。1行なら `{ }`、複数行なら `do end` が読みやすいです。

<Callout>
`drinks.map { |d| d.length }` を `drinks.select { |d| d.length >= 3 }` に変えると、
「3文字以上の飲み物だけ」の配列になります。
</Callout>
