## 辞書でカウントする

`{}` は **辞書（dict）**。「キー → 値」で情報を持ちます。
ここでは「単語 → 出現回数」です。

```python
counts[word] = counts.get(word, 0) + 1
```

- `counts.get(word, 0)` … その単語の今の回数。無ければ `0`
- そこに `+ 1` して入れ直す

## 多い順に並べる

```python
sorted(counts.items(), key=lambda pair: pair[1], reverse=True)
```

`counts.items()` は `("coffee", 3)` のようなペアの並び。
`key=lambda pair: pair[1]` で「ペアの2番目（＝回数）」を基準に、
`reverse=True` で大きい順に並べます。

<Callout>
`text.split()` は空白で文字列を区切ってリストにします。
`"a,b,c".split(",")` のように区切り文字も指定できます。
</Callout>
