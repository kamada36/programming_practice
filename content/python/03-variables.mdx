## 変数と f文字列

`=` の左に名前、右に値を書くと、その名前で値を使い回せます。

```python
price = 480
cups = 3
total = price * cups   # 1440
```

表示するときは **f文字列** が便利です。

```python
print(f"合計 {total} 円")
```

`f"..."` の `{ }` の中には、変数だけでなく `{price * cups}` のような式も書けます。

<Callout>
`cups = "3"`（クォート付き）にすると `price * cups` がエラーになります。
数として計算したい値は、クォートを付けずに書きます。
</Callout>
