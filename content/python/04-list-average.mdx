## 集計の定番関数

| やりたいこと | 関数 |
| --- | --- |
| 合計 | `sum(リスト)` |
| 個数 | `len(リスト)` |
| 最大 / 最小 | `max(リスト)` / `min(リスト)` |

平均は「合計 ÷ 個数」で計算します。

```python
average = sum(scores) / len(scores)
print(f"{average:.1f}")   # 小数第1位まで
```

## 条件でしぼり込む

```python
above = [s for s in scores if s >= average]
```

これは **リスト内包表記** で、「`scores` を1つずつ見て、`average` 以上のものだけ集める」という意味です。

<Callout>
`{average:.1f}` の `.1f` は「小数第1位まで表示」の指定です。`.2f` にすると 2 桁になります。
</Callout>
